# Reviewed production requests

No production requests are ready yet. A queue discovery is not a script approval.

A trusted default-branch JSON request must identify an existing queue item and stable SHA-256 production key, original-only rights path, primary sources, distinct value, exact reviewed script digest, four genuine editorial checks with evidence, and renderer script. The coordinator reads current repository controls and reserves the exact request in durable state before encoding. Do not place private information, credentials, media downloads or executable templates here.

`render_queue.py` deliberately does not create facts, approve its own reporting, publish a video, or treat a local file as durable delivery.
